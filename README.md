### 👋 About Me

I am a frontend-focused **Computer Science graduate** (October 6 University, B.Sc. CS, 2022–2026) with hands-on experience architecting and shipping production-grade, highly responsive web applications using **Next.js** and **TypeScript**.

- 🎯 **Core Focus**:
  - Specialized in **Next.js (App Router)**, **React**, and **TypeScript** to build scalable, high-performance web applications with clean component architecture and strict type safety.
  - Experienced with server-side rendering (SSR), static site generation (SSG), client-side interactivity, and routing hierarchies.

- 🎨 **UI/UX & Performance**:
  - Designing sleek, accessible user interfaces using **Tailwind CSS**, **Framer Motion** for micro-interactions and animations, and **Shadcn UI (Radix UI)** primitives.
  - Ensuring mobile-first responsiveness, cross-browser compatibility, Core Web Vitals optimization, and bilingual internationalization (**English & Arabic RTL** with `next-intl`).

- ⚡ **State Management & Forms**:
  - Managing scalable client and server state synchronization using **Redux**, **Zustand**, and **React Query (TanStack Query)** with smart cache invalidation.
  - Engineering robust user input workflows, automated KYC pipelines, and type-safe schema validation with **React Hook Form** and **Zod**.

- 🛠️ **Tools & Deployment**:
  - Continuous integration and automated edge deployment on **Vercel**.
  - Version control workflows with **Git & GitHub**, API integration and testing via **Postman**, cloud services with **Firebase**, and pixel-perfect design handoffs from **Figma**.

- 🎓 **Education & Diplomas**:
  - **B.Sc. in Computer Science** — October 6 University (2022 – 2026)
  - **Front-End Development Diploma** — Route IT Training Center (2025)
